InstallationInstallation

Quelques étapes, une seule fois.A few steps, only once.

📱 Android

  1. Téléchargez l'APK directement sur le téléphone (pas par WhatsApp, qui coupe les gros fichiers).
  2. Ouvrez le fichier dans Fichiers → Téléchargements, puis touchez Installer.
  3. Si Android le demande, autorisez « Installer des applications inconnues ».
  4. Si Play Protect s'affiche : Plus de détails → Installer quand même.
  1. Download the APK directly on the phone (not through WhatsApp, which cuts large files).
  2. Open it in Files → Downloads, then tap Install.
  3. If Android asks, allow "Install unknown apps".
  4. If Play Protect shows up: More details → Install anyway.
Le fichier doit faire environ 27 Mo. S'il est beaucoup plus petit, il est incomplet : téléchargez-le à nouveau.The file should be about 27 MB. If it is much smaller, it is incomplete: download it again.

💻 Windows

  1. Téléchargez et ouvrez Mikhmon-windows.exe.
  2. Si Windows affiche « Windows a protégé votre ordinateur » : Informations complémentaires → Exécuter quand même.
  3. Suivez l'installation : un raccourci Mikhmon apparaît sur le bureau.
  1. Download and open Mikhmon-windows.exe.
  2. If Windows shows "Windows protected your PC": More info → Run anyway.
  3. Follow the installer: a Mikhmon shortcut appears on the desktop.

🔌 Se connecter au routeurConnect to the router

  1. Dans Winbox, IP → Services : activez api (port 8728).
  2. Dans Mikhmon : + Ajouter un routeur, adresse (ex. 192.168.88.1), utilisateur et mot de passe MikroTik.
  3. Touchez le routeur : le tableau de bord s'affiche.
  1. In Winbox, IP → Services: enable api (port 8728).
  2. In Mikhmon: + Add a router, address (e.g. 192.168.88.1), MikroTik username and password.
  3. Tap the router: the dashboard shows up.

🔒 Accès à distance (VPN)Remote access (VPN)

  1. Routeur en RouterOS 7.12 ou plus récent, téléphone sur le wifi du routeur.
  2. Plus → Back To Home → Activer.
  3. « Activer le VPN sur ce téléphone » : le VPN s'ouvrira tout seul hors du wifi.
  1. Router on RouterOS 7.12 or newer, phone on the router's wifi.
  2. More → Back To Home → Turn on.
  3. "Turn on the VPN on this phone": the VPN opens by itself away from the wifi.

Questions fréquentesFrequently asked questions

Qu'est-ce que Mikhmon ?What is Mikhmon?

Mikhmon est une application de gestion de hotspot MikroTik pour les gérants de wifi zone : création de tickets wifi, suivi des ventes, commissions des revendeurs et accès à distance au routeur. Elle fonctionne sur Android, Windows, Linux et iPhone.Mikhmon is a MikroTik hotspot management app for wifi zone managers: wifi vouchers, sales tracking, reseller commissions and remote access to the router. It runs on Android, Windows, Linux and iPhone.

Mikhmon est-elle gratuite ?Is Mikhmon free?

Oui, l'application est gratuite et sans publicité. Vos identifiants et vos données restent sur votre appareil et sur votre routeur.Yes, the app is free and has no ads. Your credentials and data stay on your device and your router.

Avec quels routeurs MikroTik fonctionne-t-elle ?Which MikroTik routers does it work with?

Avec tous les routeurs MikroTik sous RouterOS 6 et RouterOS 7 (y compris 7.10 et plus récent), dès que le service API est activé (IP → Services → api, port 8728). Elle reprend les scripts et rapports de Mikhmon v7.13.5.With all MikroTik routers running RouterOS 6 and RouterOS 7 (including 7.10 and newer), once the API service is enabled (IP → Services → api, port 8728). It keeps the scripts and reports of Mikhmon v7.13.5.

Comment gérer mon routeur à distance ?How do I manage my router remotely?

Avec Back To Home, le VPN gratuit de MikroTik (RouterOS 7.12 ou plus récent). Dans Mikhmon : Plus → Back To Home → Activer, puis « Activer le VPN sur ce téléphone ». Le VPN ne s'active que lorsque vous n'êtes pas sur le wifi du routeur, sans adresse IP fixe.With Back To Home, MikroTik's free VPN (RouterOS 7.12 or newer). In Mikhmon: More → Back To Home → Turn on, then "Turn on the VPN on this phone". The VPN only turns on when you are away from the router's wifi, no public IP needed.

Puis-je donner un accès à mes revendeurs ?Can I give my resellers access?

Oui : chaque partenaire a son identifiant et voit, en lecture seule, ses ventes, sa commission et ses clients connectés. Les commissions sont calculées automatiquement selon le prix du ticket.Yes: each partner gets a login and sees, read-only, their sales, commission and online clients. Commissions are calculated automatically from the voucher price.
