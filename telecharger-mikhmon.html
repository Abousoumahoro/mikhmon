Télécharger Mikhmon (dernière version)

Mikhmon est l'application gratuite pour gérer votre hotspot wifi MikroTik depuis votre téléphone ou votre ordinateur. Choisissez votre appareil ci-dessous : les liens donnent toujours la dernière version testée.

Mikhmon pour Android (APK)

Fichier Mikhmon-android.apk, environ 27 Mo, pour Android 7 ou plus récent. VPN intégré (Back To Home).

📱 Télécharger l'APK Android

Téléchargez-le directement sur le téléphone : envoyé par WhatsApp, le fichier est souvent coupé et Android affiche « problème lors de l'analyse du package ». Voir le guide d'installation Android.

Mikhmon pour Windows (PC)

Installateur Mikhmon-windows.exe, environ 120 Mo, pour Windows 10 et 11 (64 bits).

💻 Télécharger pour Windows

Voir le guide Windows.

Mikhmon pour Linux

Fichier Mikhmon-linux.AppImage (64 bits) : rendez-le exécutable, puis lancez-le.

🐧 Télécharger pour Linux

Mikhmon pour iPhone

Fichier Mikhmon-iphone.ipa non signé, à installer avec Sideloadly ou AltStore depuis un ordinateur. Pour le VPN sur iPhone, utilisez l'application officielle MikroTik Back To Home.

🍎 Télécharger l'IPA

Mikhmon est-il gratuit ?

Oui. Mikhmon est gratuit, sans publicité et sans inscription. Vos identifiants restent sur votre appareil et vos données sur votre routeur MikroTik.
